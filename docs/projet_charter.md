Project Charter — Superstore Sales Dashboard (Excel)
🎯 Problématique

L’entreprise doit suivre ses performances de ventes par région, catégorie et période.
Actuellement, aucune vue consolidée n’existe → impossible d’identifier rapidement les zones performantes ou à améliorer.

🎯 Objectifs

Construire un tableau de bord Excel interactif

Suivre les KPIs clés : ventes, profit, profit ratio, quantité

Permettre une analyse par : région, catégorie, sous-catégorie, période

Fournir un outil simple pour la prise de décision

📊 KPIs

Total Sales

Total Profit

Profit Ratio

Sales by Region

Sales by Category / Sub-Category

Sales Over Time

Top 10 Products / Bottom 10 Products

🧩 Sources de données

Superstore Dataset (format Excel ou CSV)

Colonnes principales : Order Date, Ship Date, Region, Category, Sub-Category, Sales, Profit, Quantity

🛠️ Outils

Microsoft Excel

Tableaux Croisés Dynamiques (TCD)

Segments / Slicers

Graphiques dynamiques

Formules Excel : SOMME.SI.ENS, INDEX+EQUIV, MOYENNE, XLOOKUP
